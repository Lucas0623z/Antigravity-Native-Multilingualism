# Antigravity 简体中文术语表与风格规范

## 风格
- 简洁、地道，符合 Google 产品中文界面习惯（参考 Chrome / Android / Gemini 的中文 UI 用语）。
- 按钮、菜单、标签：不加句号；动宾结构简短（"Add workspace" → "添加工作区"）。
- 完整句子：使用中文全角标点（，。：？！），句末保留句号与否跟随原文。
- 中文与英文 / 数字之间加一个半角空格（"在 Git 中打开"、"最多 5 个附件"）。
- 省略号跟随原文：原文 `…` → `…`，原文 `...` → `…`。
- 键名、快捷键原样保留：Ctrl、Alt、Shift、Enter、Esc、Tab、⌘、↑ ↓ 等。
- 原文中的 `\n` 换行、前后空格、引号、括号结构、Markdown 符号必须原样保留。
- 产品与专有名词不翻译：Antigravity、Gemini、Google、Google Cloud、Firebase、GitHub、Git、MCP、WSL、SSH、JSON、API、URL、CLI、IDE、VS Code、Claude、OpenAI、Chrome、Node.js、npm、Docker、Linux、macOS、Windows、Markdown、token。
- 大小写不同但意思相同的原文，译文保持一致。
